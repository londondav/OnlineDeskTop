# Сервер OnlineDeskTop

Сервер нужен, чтобы устройства находили друг друга по ID. Если прямое соединение не получается, он ещё и передаёт трафик между ними.
Внутри два процесса из `rustdesk/rustdesk-server`:

| Процесс | Что делает | Порты |
|---|---|---|
| `hbbs` | выдаёт ID и помогает устройствам найти друг друга | 21115/tcp, 21116/tcp+udp |
| `hbbr` | передаёт трафик, если прямое соединение не получилось | 21117/tcp |

## 1. Арендуйте VPS

Хватит самого дешёвого тарифа: 1 vCPU, 1 ГБ RAM, Ubuntu 22.04 или 24.04.
Подойдут Hetzner, DigitalOcean, Vultr, любой местный хостинг или бесплатный Oracle Cloud Free Tier.
Лучше выбрать дата-центр поближе к пользователям.

В панели хостинга откройте входящие порты: **21115–21117/TCP и 21116/UDP**.

## 2. Установите сервер

Подключитесь к VPS (на Windows: `ssh root@IP_сервера`) и выполните команды:

```bash
apt update && apt install -y git
git clone https://github.com/<ваш-логин>/OnlineDeskTop.git
bash OnlineDeskTop/server/install.sh
```

В конце скрипт выведет **адрес сервера** и **публичный ключ**.

## 3. Встройте сервер в приложение

Передайте эти два значения Claude или сами пропишите их в
`libs/hbb_common/src/config.rs`:

```rust
pub const RENDEZVOUS_SERVERS: &[&str] = &["АДРЕС_СЕРВЕРА"];
pub const RS_PUB_KEY: &str = "ПУБЛИЧНЫЙ_КЛЮЧ";
```

Потом запустите сборку заново. Все клиенты новой сборки будут сразу работать через ваш сервер.

Если пересобирать не хочется, сервер можно указать вручную в каждом клиенте:
**Настройки → Сеть → ID/Relay сервер**. Там заполните поля «ID сервер» и «Key».

## Обслуживание

```bash
cd /opt/onlinedesktop
docker compose logs -f            # логи
docker compose pull && docker compose up -d   # обновление
```

Файл `/opt/onlinedesktop/data/id_ed25519` — это секретный ключ сервера. Сделайте его копию.
Если ключ потеряется, клиентам понадобится новая сборка или новый ключ в настройках.
